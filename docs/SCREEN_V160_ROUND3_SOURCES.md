# Round 3 source eligibility

Producer families are based on who made or organized the recorded work. Hosts, mirrors, and successive editions of the same event do not add producer families. The prior producer exclusions are 39C3, GDC, Blender Conference, EmacsConf, WordCamp, Debian/DebConf, Academia Sinica’s research-data recordings, FOSS4G, COSCUP, Enthusiasticon, Wikimania, FOSDEM, and PyCon Taiwan.

The selected four-recording holdout uses **Flat ODF and Git**, **Inkscape glyph decomposition**, **Linux C and Make**, and **LibreOffice as AppImage**. These cover three new producer families. **ODF-101** is the alternate Mandarin source from Yilan County Government. The direct C and Make screencast is 592 pixels high and its code is readable in the native samples.

## Reproducibility

The [source manifest](data/v160-round3-sources.json) preserves publisher metadata links, licenses, media digests and credits. Fixed source clocks come from FFmpeg/ffprobe 9.0.1 on each published rendition. The [native evidence manifest](data/v160-round3-native-evidence.json) records the clock and annotation checksums. The language spot checks used 24-second windows with MLX Whisper 0.4.3 and `mlx-community/whisper-large-v3-turbo` at `a4aaeec0636e6fef84abdcbe3544cb2bf7e9f6fb`.
