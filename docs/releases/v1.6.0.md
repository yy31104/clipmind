# ClipMind v1.6.0

Find the moments when on-screen information changes. The full pack still keeps the screenshots, OCR and transcript.
Open **Frames → Information changes** to browse the marked moments. OCR now checks dark code panels and light overlays.

On four complete held-out recordings, Mac recall was **88.51%**, precision **56.20%** and code CER **10.21%**. Docker CPU reached **88.51%**, **56.83%** and **7.82%**. Both met all three pooled targets.
Separate source-only passes of the same AI model agreed at **96.28% F1** before adjudication.
Interactive demos still produce extra boundaries, and code CER covers two recordings.
