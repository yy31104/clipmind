# ClipMind v1.3.0
ClipMind turns videos into searchable speech, screen text and timestamped images for people and AI agents.

Install with `uv tool install --python 3.12 git+https://github.com/yy31104/clipmind.git@v1.3.0`, then run `clipmind serve`.
For Docker, run `docker run --rm -p 127.0.0.1:8420:8420 -v clipmind-data:/data ghcr.io/yy31104/clipmind:v1.3.0`.
See [platform dependencies](https://github.com/yy31104/clipmind/blob/v1.3.0/docs/INSTALL.md); the unrelated PyPI package named `clipmind` is not this project.
Set `CLIPMIND_ASR_LANGUAGE=en` for English. This version defaults to Chinese.

Changes: safer acquisition cleanup and cancellation, Bilibili part-aware reuse, Douyin browser fallback, recoverable Library removal, complete-frame browsing and reading exports.
The [real demo](https://github.com/yy31104/clipmind/blob/v1.3.0/docs/REAL_TALK_DEMO.md) searches a complete 39-minute talk and uses MCP to retrieve its evidence.
The [ten-clip benchmark](https://github.com/yy31104/clipmind/blob/v1.3.0/docs/REAL_TALK_BENCHMARK.md) exposes missed screen changes and weak code OCR. AI-assisted annotations; human review pending.
Temporary media are cleaned; results, model weights, exports and recoverable trash remain. Docker uses CPU inference and has no Chrome fallback.
Wheel, source, demo and benchmark inputs are attached with checksums. Media retain their source attribution and licenses.
The [MCP Registry entry](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.yy31104%2Fclipmind/versions/1.3.0) is active. No PyPI upload or signed desktop installer is included.
