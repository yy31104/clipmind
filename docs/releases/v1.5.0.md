# ClipMind v1.5.0
ClipMind extracts searchable speech, screen text and timestamped images from videos.

Screen states are compared with the last information screen, so speaker, camera, pointer and transition states stay saved but are no longer counted as new information.
Code OCR keeps trailing comments on their line, recovers thin small text on Mac, and reads dark code panels inside light slides with Tesseract.
Development set (ten excerpts plus the former holdout): recall 99.28% → 94.20% on both; precision Mac 23.42% → 41.27%, Docker 23.46% → 34.48%; code CER Mac 15.95% → 10.20%, Docker 17.40% → 12.69%.
New holdout, three complete talks (69 min, English and Mandarin), one run per backend: recall Mac 92.86%, Docker 95.05%; precision 33.87% / 24.96%; code CER 22.45% / 13.18%.
Recall meets 85% on both and Docker code CER meets 15%. Precision misses 50% on both; Mac code CER misses 15%. No tuning or rerun after the result.
AI-assisted annotations; human review pending. The holdout review package has a blank CSV.
