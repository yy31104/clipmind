# ClipMind v1.4.0
ClipMind extracts searchable speech, screen text and timestamped images from videos.

Progressive builds keep fuller images and actual capture times. Supported speaker motion is labeled separately. Code OCR improves contrast and reading order; native worker failures have bounded cleanup.
Speech language defaults to detection. Tesseract prefers English first while retaining Chinese models; overrides remain available. Tasks show an analysis-time range.
Development capture: 44/60 → 59/60. Code CER: Mac 39.29% → 6.24%; Docker 54.30% → 23.61%.
Single holdout campaign, three complete talks: both backends capture 73/78 (93.59%). Precision is Mac 20.39% / Docker 20.28%; code CER is 19.00% / 16.08%.
Recall meets 85%; precision misses 50% and code CER misses 15%. All results and failures remain public; no post-result tuning or replacement run.
These results use the original AI-assisted labels. Known timing/transcription discrepancies remain in the frozen references. All 15 code ROIs are from one English talk; Chinese code OCR is N/A.
