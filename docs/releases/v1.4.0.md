# ClipMind v1.4.0

ClipMind extracts timestamped speech, screen text and images from videos.

- Retain progressive screen builds and record actual screenshot times.
- Distinguish supported speaker motion, improve code OCR contrast and reading order, and bound native OCR failures.
- Detect speech language automatically. Tesseract defaults to English first while retaining both Chinese models; environment overrides remain available.
- Show a broad analysis-time range before speech recognition and OCR.

[Quality measurements](../SCREEN_QUALITY.md) include missed changes, extra boundaries, OCR errors, CPU timings and default-tool comparisons. Annotations are AI-assisted; human review is pending.

Use the [installation instructions](../INSTALL.md), then run `clipmind serve`. Results, model weights and recoverable trash remain on disk; temporary media are cleaned.
